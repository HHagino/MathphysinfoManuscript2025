## 概要 / Overview

このリポジトリは、「頻度論 vs ベイズ推論」という統計的構造の差異を、  
情報空間における貼り合わせ構造とコホモロジーの観点から再定義し、  
KLダイバージェンス、エントロピック重力、ロジスティック補間構造、  
ローレンツ変換の双曲関数構造との接続を試みる理論草稿のメモ集です。

---

## 理論の中核 / Core Ideas

- 頻度論：真の関数を関数空間の1点と仮定（デルタ的）
- ベイズ論：ラベル空間の測度を可測構造とみなす（sheaf構造）
- ベイズ更新 = 貼り合わせ操作 → Čech 1-コサイクル
- KLダイバージェンス = ねじれ（貼り合わせ障害） → Čech 2-コサイクル
- BE vs FD統計 = trivial vs torsion cocycle
- 修正重力 = ロジスティック関数 = フェルミオン版プランク法則
